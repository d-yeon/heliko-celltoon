# 헬리코의 인실리코 세포툰

DNA 캐릭터 **헬리코**와 함께 세포생물학 교과서(「필수세포생물학」 6판)를 절마다 10장 남짓의 컷툰으로 정리하는 인스타그램 연재 보관소예요.
실험을 컴퓨터로 대신하는 **인실리코(in silico)**를 공부하려고 세포부터 다시 보고 있어요. 매화 마지막 장은 "인실리코 한 줄"이에요.

- 비공식 학습 노트예요. 그림은 모두 직접 그렸고 교재의 사진·도판은 쓰지 않았어요.
- 매일 12:00(한국 시간)에 한 화씩 인스타그램에 올라가고, 올라간 화는 아래 목록과 `episodes/`에 자동으로 정리돼요.
